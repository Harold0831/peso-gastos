# Peso

PWA personal de rastreo de gastos e ingresos, con importación automática de
notificaciones del banco Qik desde Gmail y categorización con Gemini.

- **Stack**: Next.js 15 · TypeScript · Tailwind v4 · Supabase · Vercel
- **Docs completas**: ver [CLAUDE.md](CLAUDE.md) — arquitectura, setup de
  Gmail/Supabase/passkeys, parser de correos y decisiones técnicas.

```bash
npm install
npm run dev   # corre con datos mock si no hay .env.local
```
